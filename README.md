# Comfy Manager

当前稳定版本：`v3.3.1`

Comfy Manager 是一个面向 **ComfyUI output 目录** 的桌面整理工具，基于 **Wails v2 + Go + Vue 3** 构建。  
它不是单纯的“看图器”，而是把 ComfyUI 出图之后真正高频的事情串成一个完整工作流：

- 回看最近产出
- 按日期、模型、LoRA、标签、收藏、笔记快速筛图
- 查看 PNG 元数据、Prompt 和 Workflow
- 整理目录、清理缓存、治理侧边栏目录结构
- 通过提示词助手、模板和自动规则提高复用效率

## v3.3.1 这次有什么变化

`v3.3.1` 是一次 UI 可访问性与视觉一致性打磨：在保留 `v3.3.0` 功能与性能优化的基础上，补齐键盘 / 读屏支持，统一对比度、圆角与字号，并修复壁纸模式下的可读性问题。

### 1. 可访问性

- 全项目图标按钮、开关、滑杆、输入框补齐 `aria-label` / `aria-pressed` / `aria-busy`，支持纯键盘操作。
- 统计图表、热力图、图片卡片补充语义与状态；图片卡片改为真实按钮覆盖层，避免交互元素嵌套。
- 全局焦点环、控件边界达到 3:1 以上；浅色次要文字提升到 5:1。

### 2. 对比度与主题

- 修复深色 + 壁纸模式下提示气泡「浅底浅字」的问题。
- 修复首页「最近作品」文字遮罩在壁纸模式下失效，改为不受透明度影响的多段柔和渐变。
- 深色主题重新建立背景 / 侧栏 / 卡片 / 弹层层级；Toast 与确认弹窗跟随主题。
- 图片 HUD、元数据面板、胶片条等悬浮层的小字整体提亮。

### 3. 视觉一致性

- 圆角统一：卡片 `rounded-2xl`、控件 `rounded-xl`，清理全部任意圆角。
- 字号下限统一为 11px；滚动条改为主题令牌。
- 小窗筛选区改为两行布局，窄窗口不再挤压截断。

## v3.3.0 历史更新

`v3.3.0` 聚焦「图库更清爽、下拉更好用、大盘更快」：移除了 3D 环绕视图，重做了全项目下拉菜单，并完成一轮后端扫描与缓存优化。

- 图库只保留网格视图，移除 3D 环绕入口与样式。
- 新增自绘下拉组件 `AppSelect`，替换全部原生下拉；模型 / LoRA / 标签支持搜索、固定宽度与键盘操作。
- 元数据缓存单条读写 + 原子写盘；轻量分页支持筛选；健康检查合并；缩略图并发限制。
- 修复编码乱码与 JSON 半截写盘问题；新增后端单元测试。

## v3.2.0 历史更新

`v3.2.0` 是一次围绕“看图体验”的更新：重做了大图查看器，并新增背景壁纸自定义。

### 1. 大图查看器（灯箱）增强

- **氛围画廊**：按当前图片主色渲染两侧光晕，主图下方加地面倒影，换图时走“相纸显影”动效，鼠标移动带极轻微视差。
- **底部缩略图导航条**：横向滚动的胶片条，当前图自动居中并高亮，点任意缩略图直接跳转；右侧按钮一键呼出批次概览。
- **批次概览层**：按 `空格` 在当前批次上盖一层半透明缩略图矩阵，支持「同日 / 同模型 / 同提示词 / 连拍组」切换分组，点击即跳、跳完自动收起。
- **参数 HUD**：画面浮出模型 / 采样器 / 调度器 / seed / steps / CFG，放大时还会显示“当前视野在原图的哪个位置”，可随时开关。
- **连拍组改为 3D 层叠卡牌**：悬停散开、点击抽卡，替代原来的“1 / 3”角标。
- **灵动小窗的图片详情也支持缩放与拖动**，和主窗口大图体验对齐。

### 2. 背景壁纸自定义

- 入口在 **个人中心 → 外观与偏好 → 背景壁纸**。
- 支持本地选图，图片会复制到 `data/wallpaper`，原图移动或删除都不影响显示。
- 可调：启用开关、填充方式（铺满 / 完整 / 原始）、压暗强度、面板不透明度、面板毛玻璃。
- 侧栏、卡片、对话框会半透明地透出壁纸。

### 3. 修复

- 修复开发模式下图片全部无法显示的问题（vite 的 SPA 回退把图片请求返回成了 HTML）。

## v3.1.5 历史更新

`v3.1.5` 主要是优化了第三方词库导入功能，并随包附赠了 NAI4 完整标签库：

- 解除了词库“外部导入”功能与系统内置词库的强制查重过滤，允许玩家原汁原味、100% 独立地导入完整的第三方词库。
- 将抓取的 6995 个 NAI4 标签整理成独立的 JSON 文件（并且优化了中英文的分类字段映射），方便用户批量导入使用。
- 同步更新打包安装器。

## v3.1.4 历史更新

`v3.1.4` 是在 `v3.1` 基础上的优化版本，重点修复了提示词分类导致的 UI 卡顿和乱分类问题：

- 优化提示词库分类算法，采用更精准的英文单词边界+中文词组匹配。
- 修复“作品IP”和“未分类”词条杂糅问题，将 14000+ 角色重新归类为“人物角色”。
- 扩充物品库，大幅提升“服装”、“物品道具”类的分类准确率。
- 修复提示词分类下拉框卡顿问题：子分类强制简化为 A~Z 字母表，解决生成上万微型子分类导致的 DOM 渲染瓶颈。

## v3.1 的核心变化

`v3.1` 重点是把灵动图库小窗、分页、应用内确认弹层、安装器和文档一次收口：

- 后端 Go 源码从根目录整理进 `desktop-source/backend/`
- 修复重构后前端对 Wails 绑定名的兼容问题
- 新增右下角灵动图库小窗，支持置顶、恢复主窗口、刷新、目录切换、搜索和快速查看

## 核心能力

- 绑定任意 ComfyUI `output` 目录，而不是依赖 exe 的相对位置
- 同时浏览默认目录、日期归档目录和自定义目录
- 工作台总览、日期产出工作台、收藏夹、数据视界
- 模型 / LoRA / 标签 / 笔记 / 收藏联合筛图
- 模型 / LoRA / 标签下拉支持搜索与键盘操作，深色 / 浅色主题自动适配
- PNG 元数据、Prompt、Workflow 查看与复制
- 大图查看器：氛围光晕与倒影、缩略图导航条、批次概览层、参数 HUD、层叠连拍组
- 背景壁纸自定义：本地选图、压暗、面板不透明度与毛玻璃
- 提示词助手、提示词模板与本地词库复用
- 自动规则：按模型、LoRA、Prompt、文件名自动打标或归类
- 目录健康中心、空文件夹清理、缓存治理
- 回收站保护与恢复
- 快捷键、工具菜单、性能模式等设置中心能力
- 灵动图库小窗：适合边生成边看图、批量筛选、临时置顶观察最新 output

## 快速开始

### 1. 安装或直接运行

- 安装版：运行根目录的 [ComfyManager-amd64-installer.exe](./ComfyManager-amd64-installer.exe)
- 便携版：直接运行根目录的 [desktop-app.exe](./desktop-app.exe)

### 2. 首次进入先绑定 output

从 `v2.x` 开始，程序不再猜测 exe 的上级目录。首次进入会要求你手动选择 **ComfyUI 的真实 output 文件夹**。

正确示例：

```text
D:\AiImg\ComfyUI-aki-v3\ComfyUI\output
```

不是选择：

```text
D:\AiImg\ComfyUI-aki-v3\ComfyUI\output\comfy-manager
```

绑定完成后，程序会自动识别：

- `rootDir`：`output` 的上一级目录
- `outputDir`：当前绑定的真实输出目录

### 3. 建议第一轮使用顺序

1. 先看“工作台总览”，确认最新作品、总量和占用是否正常
2. 再进“日期产出”，按今天、昨天、最近 7 天回看近期创作
3. 需要细筛时进入“默认目录”或自定义目录图库
4. 常用 Prompt 与模板建议放进“提示词助手”统一复用
5. 需要边做图边观察 output 时，从侧边栏打开“灵动图库小窗”
